# Mom's Health Tracker 🩺

A personal health tracking app for monitoring CBC, eosinophil counts (HES), medications, and medical documents.

## Features
- 📊 Dashboard with live HES Watch panel
- ✨ AI-generated health summary
- 🔬 Lab results with AI parsing (upload photo/PDF)
- 📈 Trend charts over time
- 💊 Medication tracker
- 📋 Doctor visit notes
- 📁 File storage for medical documents
- 🔐 PIN-protected editor mode / view-only for patient

## Setup
1. Open the app (deployed via GitHub Pages)
2. Click **⚙ API Key** in the sidebar and enter your Anthropic API key
3. Click **🔑 Editor Access** to set your PIN and unlock editing
4. Start uploading lab results!

## Notes
- Data is stored in browser localStorage — private to each device
- AI features require an Anthropic API key (get one at console.anthropic.com)
